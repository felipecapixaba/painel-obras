# Painel de Obras — demonstração

**No ar em https://felipecapixaba.github.io/painel-obras/**

Demonstração pública do painel de custo de obra da Capixaba Shop. Abre com a
**Construtora Atlântica**, uma empresa fictícia com quatro obras e doze meses de
lançamentos, e mostra o painel inteiro funcionando: custo realizado contra
orçado, composição por obra, ranking de etapas e de fornecedores, filtro cruzado
e tabela de lançamentos.

Os números são inventados e estão marcados como tal na própria tela.

## O que esta versão não faz

Não carrega planilha. É demonstração: serve para ver o produto, não para operar
com dados reais. Quem quiser o painel com os números da própria construtora fala
com a Capixaba Shop pelo botão do topo.

## A história que os dados contam

| | |
|---|---|
| Custo realizado | R$ 7,94 milhões |
| Saldo do orçamento | −R$ 612 mil |
| Orçamento consumido | 108% |
| Obra fora de controle | Residencial Vista Mar, 26% acima do orçado |

As outras três obras estão dentro ou abaixo do previsto. É o caso comum: o
consolidado parece administrável e uma obra sozinha está consumindo a margem das
demais. Clicar na obra filtra o painel inteiro.

## Como chegar aqui

A [calculadora de estouro de obra](https://felipecapixaba.github.io/calculadora-obra/)
é a porta de entrada: a pessoa calcula a projeção da obra dela, vê o tamanho do
problema e chega até esta demonstração.

## Esta pasta

Gerada por `ferramentas/gerar-app.js --demo` no projeto `painel-bi`. Não editar à
mão — rodar o gerador de novo sobrescreve tudo.
